How can your cousins become less related to you while there are more of them?

Move outward through a family tree and compare genetic closeness with the number of possible relatives.

Relatedness

50% → 0.05%

Full siblings have an expected relatedness of 50%. By 5th cousins, the pedigree-based expectation falls to about 0.05% — roughly 1 part in 2,000.

Headcount

2 → ~1,000

Assuming roughly 3 children per family across the generations it takes to get there (a rough historical average, not a real prediction for any one family), the pool of people at each distance roughly triples every step out.

The farther out you go, the less related each cousin is — but the more cousins there can be.
Expected DNA falls rapidly while the number of branches in a family tree can expand.

How can something become individually smaller while becoming collectively much larger?

How cousin names work

Start with the shared ancestor

Same parent → siblings.
Same grandparent → 1st cousins.
Same great-grandparent → 2nd cousins.
Same great-great-grandparent → 3rd cousins.

Then ask whether you are in the same generation

If you are, there is no “removed.” If one person is one generation above or below the other, the relationship is once removed. Two generations apart means twice removed.

2nd cousins You share great-grandparents and are in the same generation.
3rd cousins You share great-great-grandparents and are in the same generation.
3rd cousin once removed You share the same ancestral line used for a 3rd-cousin relationship, but one of you is one generation above or below the other.
